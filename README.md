# 🛡️ Protege+

## Sistema Inteligente de Denúncias para Proteção do Cidadão

O **Protege+** é uma solução GovTech desenvolvida no contexto do **HackGov – Enterprise Challenge EGESP**, com foco na transformação digital do setor público através do uso de **Ciência de Dados, Inteligência Artificial e análise estratégica de informações**.

A plataforma foi criada para oferecer um canal digital de denúncias **mais seguro, acessível, inteligente e eficiente**, permitindo que cidadãos realizem denúncias de forma rápida, inclusive de maneira anônima, enquanto órgãos públicos obtêm dados estratégicos para tomada de decisão.

---

# 📌 Sobre o Projeto

O Brasil enfrenta um grande problema de **subnotificação de violência**, causado por medo, burocracia e dificuldade de acesso aos canais tradicionais de denúncia.

O **Protege+** surge como uma alternativa moderna e acessível, permitindo o registro de denúncias relacionadas a:

➽ Violência doméstica  
➽ Assédio  
➽ Abuso sexual  
➽ Violência contra crianças e idosos  
➽ Discriminação  
➽ Situações de risco e emergência  

Tudo isso através de uma interface simples, intuitiva e acessível diretamente pelo navegador.

# 🤖 Ciência de Dados & Inteligência Artificial

O Protege+ possui integração com conceitos de Ciência de Dados e IA para transformar denúncias em inteligência estratégica.

## 📊 ScoreSystem Inteligente

Cada denúncia recebe automaticamente um **score de confiabilidade** de 0 a 100 baseado em:

➽ Quantidade de informações preenchidas  
➽ Qualidade da descrição  
➽ Existência de evidências  
➽ Dados de localização  
➽ Informações complementares  

Classificação:

🟢 Alta confiabilidade  
🟡 Média confiabilidade  
🔴 Baixa confiabilidade
